# IS219 Final Portfolio

This portfolio website showcases multiple web development projects, demonstrating skills in front-end and back-end development.

## Projects

### 1. Data Visualization Project

An interactive data visualization project built with:
- D3.js
- JavaScript
- React
- Data Analysis techniques

Located in: `/public/project1`

### 2. AI Streaming Chat

A real-time AI chat application with streaming responses, featuring:
- Node.js and Express backend
- Server-Sent Events (SSE) for streaming
- Customizable AI character persona
- Responsive web design

Located in: `/public/project2`

## Portfolio Features

- Responsive design
- Project showcase
- Skills section
- About and contact information
- Next.js-based architecture

## Running the Portfolio

```bash
npm install
npm run dev
```

The portfolio will be available at http://localhost:3000
